Tests Module

Homepage shows only featured tests.

Click "See All"

↓

Open All Tests page.

All Tests page must include:

- Search Bar
- Category Filter
- Professional Test Cards

Every Test Card contains:

- Image
- Test Name
- Price
- Short Description
- Book Now button
- Add to Cart button

Important:
Clicking anywhere on the Test Card must open the dedicated Test Details Page.

Only the Book Now button performs booking.

Do NOT redirect Test Cards to the All Tests page.

Every test must have its own dynamic details page.

Examples:

- CBC
- Vitamin D
- Vitamin B12
- Lipid Profile
- KFT
- LFT
- Thyroid Profile

Each Test Details Page includes:

- Hero Banner
- Test Name
- Category
- Price
- Description
- Why this test is required
- Preparation Before Test
- Fasting Required or Not
- Sample Type
- Report Delivery Time
- FAQ
- Related Tests
- Book Now
- Add to Cart
- WhatsApp
- Call Now
- Breadcrumb Navigation

Use reusable dynamic routing for all tests.
